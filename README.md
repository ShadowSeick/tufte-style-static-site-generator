# ETF Site Generator
This is a tool to generate from markdown files static sites with tufte CSS. The idea is for blog pages, but it could be used for much more. What more? I don't know

[Tufte CSS](https://edwardtufte.github.io/tufte-css/)
[Markdown syntax](https://www.markdownguide.org/)
## Translations
- IDs will be generated as the markdown syntax denotes {#some-id}
- Pounds will be translated 1 to 1 to headers. h1 / h2 / h3 tags will be taken from the markdown counterpart, just reading the number of pounds.
